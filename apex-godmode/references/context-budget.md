# Context Budgeting

Quality is not the same as reading everything repeatedly.

## Rules
- Read broad structure once during recon.
- Read full files only when they are material to the task.
- Prefer focused ranges/searches for iteration.
- Keep research summaries compact and source-linked.
- Load reviewers and phase references only when their domain is relevant.
- Preserve an evidence ledger so completed work does not need to be rederived from scratch.

## Escalate breadth when
- a contract changed
- a new dependency appeared
- a hidden caller was discovered
- an initial assumption was invalidated
- runtime behavior contradicts static reasoning
