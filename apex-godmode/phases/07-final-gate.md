# Phase 7 — Final Gate

Do not deliver until all required gates are explicitly resolved.

## Required gates

- acceptance criteria: PASS
- implementation completeness: PASS
- targeted tests: PASS or justified N/A
- regression/type/build checks: PASS or justified N/A
- anti-pattern research: COMPLETE
- anti-pattern recheck: PASS
- reviewer findings: no blocking finding
- evidence integrity: PASS
- changed-file inventory: COMPLETE
- unrelated diff: CLEAN

## For high-risk work

Also require, when applicable:
- runtime/integration evidence
- security checks
- rollback/recovery assessment
- data integrity check
- observability/retry/cancellation check

## Delivery truthfulness

Never convert BLOCKED, SKIPPED, or UNVERIFIED to PASS.
A final report must separate:
- proven
- inferred
- not tested
- unavailable

The result is "complete" only when the required gate set passes.
